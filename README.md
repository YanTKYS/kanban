# iKanban

個人用の小さなKanbanツールです。`iKanbanPilot.html`（UI検証用Pilot版）と `iKanban.html`（実用最小版）の2ファイルで構成されています。

## ファイル構成

- **`iKanban.html`** — 実用最小版。カードの追加・編集・削除・移動・並び替えができ、内容は `localStorage` に保存されます。日常的に使うのはこちらです。
- **`iKanbanPilot.html`** — UI検証用のPilot版。Kanbanの操作感とテーマ切替の見え方を確認するために作成したもので、検証済みの記録として残しています。カード内容は保存されません。

## 起動方法

いずれのファイルもブラウザで直接開くだけで動作します。ビルドやサーバーは不要です。

```
open iKanban.html
```

## `iKanban.html` の主な機能

- 4列のKanbanボード（未着手 / 作業中 / 確認待ち / 完了）と各列の件数表示。列ヘッダーとカード追加導線は常に固定表示され、カード一覧は列ごとに独立して縦スクロールします（1列のカードが増えても他列の高さや操作性には影響しません）
- カードの追加（タイトル必須、補足は任意）。追加後もフォームは開いたままなので、続けて何枚でも登録できます
- カードの編集（カードのタイトルをクリックしてインライン編集）
- カードの削除（誤操作防止のため確認ダイアログを表示）
- ドラッグ＆ドロップによる列間移動、および同一列内での並び替え。ドロップ位置はマウスの位置から判定するため、カードとカードの隙間に落とした場合も挿入線が示した位置に入ります
- テーマ切替（Light / Dark / Blue）。CSS Custom Propertiesで配色を管理し、レイアウトはテーマ間で共通。保存値が3種類以外の想定外の値だった場合はLightへ安全にフォールバックします
- 列の表示名を変更できます。各列ヘッダーの鉛筆アイコンから編集し、保存／キャンセルできます。内部的な列の区分（未着手→`todo`、作業中→`doing`、確認待ち→`review`、完了→`done`）は固定で、変更できるのは表示名のみです。空文字だけの列名は保存されません
- 初期状態へのリセット機能（確認ダイアログあり。カード内容・配置・並び順が対象。列の表示名とテーマ設定はリセット対象に含めていません）
- Kanban全体をJSONファイルへバックアップ出力・そのファイルからの復元ができます（詳細は下記「バックアップ・復元について」）

## データ保存について

- カードの内容・所属列・並び順、選択中のテーマ、列の表示名は、ブラウザの `localStorage` に保存されます（それぞれ別のキーで管理）
- 保存はカードの追加・編集・削除・移動・並び替え・テーマ変更・列名変更のたびに行われ、ページ再読み込みやブラウザ再起動後も復元されます
- 初回起動時のみサンプルカードが表示されます。一度でも操作すると、以降はその内容が保持され、サンプルには戻りません
- 保存先はこのブラウザのlocalStorageのみです。サーバーやクラウドへの送信は行われません。ブラウザのデータ（サイトデータ／閲覧履歴）を削除すると、Kanbanの内容も失われます
- 読込時は保存データの構造（各列がカードID配列になっているか、参照しているIDが実在するか等）を検証します。破損したデータを検出した場合は、まず別キーへの退避を試み、退避できたときに限り初期データで復旧します。退避に失敗した場合は元データを上書きせず、その回は初期データで安全に表示します

## バックアップ・復元について

- ヘッダーの「バックアップ出力」から、現在のKanban全体（カード内容・所属列・並び順・列の表示名・選択中のテーマ）を1つのJSONファイルとしてダウンロードできます。ファイル名には日時が含まれるため、複数回出力しても判別できます
- ヘッダーの「バックアップ復元」から、出力したJSONファイルを選択して復元できます。復元前には確認ダイアログを表示します
- 復元時はファイルの形式・内容を検証します（iKanbanの出力形式か、対応しているバージョンか、カードや列の参照が壊れていないか等）。検証に失敗した場合は現在のKanbanの内容を一切変更せず、復元失敗を画面上に表示します
- 復元直前の状態は、固定の1つのキー（`ikanban.beforeRestore.v1`）へ自動的に退避されます。退避は復元のたびに上書きされる**直前1世代分のみ**で、複数世代の履歴は保持しません
- ヘッダーの「直前の復元を取り消す」から、直前1回分の復元前の内容（カード内容・配置・並び順・列の表示名・テーマ）へ戻せます。取り消し前には確認ダイアログを表示し、取り消せる内容がない場合はボタンが無効化されます。取り消しを実行すると、その退避データは消費されます（さらに前の状態へは戻せません）
- 復元・取り消しのいずれも、必要なデータ（ボード・列の表示名・テーマ）の保存に失敗した場合は「完了」として扱わず、可能な範囲で処理前の内容へ戻したうえで失敗を画面上に伝えます
- 復元は4列の内部構造（todo / doing / review / done）を前提としたバックアップ用途です。列の追加・削除や複数ボードの管理には対応していません

## 外部依存

外部CDN・外部API・外部ライブラリは使用していません。HTML / CSS / JavaScriptのみで構成され、オフラインでも動作します。

## `iKanbanPilot.html`（Pilot版）について

Kanban UIおよびテーマ切替の操作感を検証するための版で、`iKanban.html` の土台になっています。テーマ設定のみ `localStorage` に保存され、カード内容やカード配置は保存されません（再読み込みで初期状態に戻ります）。
