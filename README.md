# iKanbanPilot

Kanban UIの操作感と、複数テーマを切り替えた際の見え方・使いやすさを比較検証するためのPilot版です。

## 目的

本格的なタスク管理システムの構築が目的ではありません。以下を確認することを目的としています。

- Kanbanとして自然に操作できるか
- カードや列の情報量は適切か
- テーマ変更によってどの程度UIの印象が変わるか
- 単一HTMLでも保守しやすい構成にできるか

## 起動方法

`iKanbanPilot.html` をブラウザで直接開くだけで動作します。ビルドやサーバーは不要です。

```
open iKanbanPilot.html
```

## 現在の機能

- 4列のKanbanボード（未着手 / 作業中 / 確認待ち / 完了）
- 各列の件数表示（カード移動時に即時更新）
- 業務タスクを想定したサンプルカード（担当・期限・完了日を表示）
- ドラッグ＆ドロップによる列間のカード移動
- テーマ切替（Light / Dark / Blue）、CSS Custom Propertiesによる配色管理
- 選択中テーマの `localStorage` への保存・復元

## Pilot版について

本ツールはPilot版であり、Kanban UI自体の操作感とテーマの見え方を実機で確認するためのものです。完成度の高いタスク管理ツールを目指すものではなく、ログイン・サーバ通信・API・データベース・カード詳細画面・検索・フィルターなどは実装していません。

## 外部依存

外部CDN・外部API・外部ライブラリは使用していません。HTML / CSS / JavaScriptのみで構成され、オフラインでも動作します。

## データ保存について

保存対象はテーマ設定のみです（`localStorage`）。カードの配置やタスク内容は保存されず、ページを再読み込みすると初期状態に戻ります。
