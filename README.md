# iKanban

個人用の小さなKanbanツールです。単一のHTMLファイルで動作し、ビルドもサーバーも必要ありません。

## ファイル構成

- **`iKanban.html`** — 実用版。日常的に使うのはこちらです。
- **`iKanbanPilot.html`** — UI検証用のPilot版。Kanbanの操作感とテーマ切替の見え方を確認するための版で、`iKanban.html` の土台になっています。テーマ設定のみ保存され、カードの内容や配置は保存されません。

## 起動方法

ブラウザで直接開くだけで動作します。

```
open iKanban.html
```

`main` へ `iKanban.html` をpushすると、GitHub Actions（`.github/workflows/pages.yml`）がGitHub Pagesへ自動デプロイします。

## 主な機能

- **4列のKanbanボード**（未着手 / 作業中 / 確認待ち / 完了）と各列の件数表示。列ヘッダーとカード追加導線は固定表示で、カード一覧は列ごとに独立して縦スクロールします
- **カードの追加** — タイトル必須、補足は任意。追加後もフォームは開いたままなので、続けて何枚でも登録できます
- **カードの編集** — カードのタイトルをクリックしてインライン編集
- **カードの削除** — 確認ダイアログあり
- **ドラッグ＆ドロップ** — 列間の移動と同一列内の並び替え。ドラッグ中にカードを列の上端・下端へ近づけると一覧が自動スクロールします
- **テーマ切替**（Light / Dark / Blue） — CSS Custom Propertiesで配色を管理し、レイアウトはテーマ間で共通です
- **列の表示名の変更** — 各列ヘッダーの鉛筆アイコンから編集します。変更できるのは表示名のみで、内部的な列の区分（未着手→`todo`、作業中→`doing`、確認待ち→`review`、完了→`done`）は固定です
- **初期状態へのリセット** — 確認ダイアログあり。カードの内容・配置・並び順が対象で、列の表示名とテーマ設定は変更されません
- **バックアップの出力・復元** — Kanban全体をJSONファイルへ書き出し、そこから復元できます（下記参照）

## データ保存について

- カードの内容・所属列・並び順、選択中のテーマ、列の表示名を、ブラウザの `localStorage` にそれぞれ別のキーで保存します
- 保存はカードの追加・編集・削除・移動・並び替え・テーマ変更・列名変更のたびに行われ、ページ再読み込みやブラウザ再起動後も復元されます
- サンプルカードが表示されるのは初回起動時のみです。一度でも操作すると、以降はその内容が保持されます
- サーバーやクラウドへの送信は行いません
- ブラウザの設定や保存容量の都合で保存できなかった場合は、ページを開いている間に一度だけダイアログでお知らせします。気づかないまま操作を続けて、再読み込み時に内容を失うことを防ぐためです
- 読込時は保存データの構造（各列がカードID配列になっているか、参照しているIDが実在するか、カードの中身が表示できる形になっているか）を検証します。破損を検出した場合はまず退避を試み、退避できたときに限り初期データで復旧します。退避に失敗した場合は元データを上書きせず、その回だけ初期データで表示します

## バックアップ・復元について

- ヘッダーの**「バックアップ出力」**から、現在のKanban全体（カードの内容・所属列・並び順・列の表示名・選択中のテーマ）を1つのJSONファイルとしてダウンロードできます。ファイル名には日時が含まれます
- ヘッダーの**「バックアップ復元」**から、出力したJSONファイルを選んで復元できます。復元前には確認ダイアログを表示します
- 復元時はファイルの形式・内容を検証します（iKanbanの出力形式か、対応しているバージョンか、カードや列の参照が壊れていないか）。検証に失敗した場合は現在の内容を一切変更せず、復元失敗を画面上に表示します
- 復元直前の状態は自動的に退避され、ヘッダーの**「直前の復元を取り消す」**から元に戻せます。取り消し前には確認ダイアログを表示し、取り消せる内容がない場合はボタンが無効になります
- 復元・取り消しのいずれも、必要なデータ（ボード・列の表示名・テーマ）をすべて保存できた場合にだけ画面を切り替えます。途中で保存に失敗した場合は処理前の保存内容を書き戻し、表示は変更せずに失敗を伝えます

## 既知の制限

- **保存先はこのブラウザの `localStorage` のみです。** ブラウザのデータ（サイトデータ／閲覧履歴）を削除すると、Kanbanの内容も失われます。別のブラウザや別の端末との共有もされません。大事な内容は「バックアップ出力」でファイルへ書き出してください
- **「直前の復元を取り消す」で戻せるのは直前1回分のみです。** 退避データは固定の1キー（`ikanban.beforeRestore.v1`）へ復元のたびに上書きされ、取り消しを実行すると消費されます。さらに前の状態へは戻せません
- **破損データの退避先も固定の1キー（`ikanban.board.v1.corrupted`）で、退避のたびに上書きされます。** 世代は残しません（保存容量が足りない状況で、使えないコピーだけが際限なく溜まるのを防ぐためです）

## 外部依存

外部CDN・外部API・外部ライブラリは使用していません。HTML / CSS / JavaScriptのみで構成され、オフラインでも動作します。
